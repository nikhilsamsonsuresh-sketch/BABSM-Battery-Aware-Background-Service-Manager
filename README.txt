BABSM System Dashboard

1. Extract the ZIP file.
2. Open index.html in Chrome or Edge.
3. Move the battery slider or toggle Charger connected.
4. Click Run BABSM Scheduler to recalculate decisions.
5. Add tasks using the Instagram Refresh and Important Alert buttons.
6. Use Load Demo Tasks or Reset Demo to restore the 15-task example.

This is a browser simulation. It does not read the real device battery or control actual apps/Windows processes.
